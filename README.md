  <summary></summary>
   
### 4.0.0—26.x
* Added support for Minecraft 26.1, 26.1.1, and 26.1.2
* Updated baby bee texture to match Minecraft 26.1
### 3.1.0—1.21.x
* Split 1.21.5-1.21.11 into three separate version ranges to account for API differences across minor versions
* Fixed a crash on 1.21.2–1.21.3 caused by a styling API that was not available until 1.21.4
* Fixed a crash on 1.21.5 caused by a rendering API that was not available until 1.21.6
* Fixed a crash on 1.21.6–1.21.8 caused by a rendering API that was not available until 1.21.9
### 3.0.0—1.21.x
* Added multi-version support covering Minecraft 1.21 through 1.21.11
* Replaced flat bee PNG icons with live 3D paper doll rendering, similar to how your character appears in the inventory screen
* Increased the GUI container to better accommodate the new bee renders
* Repositioned the bee slots and honey bar to fit the updated layout
### 2.0.0—1.21.11
* Updated to Minecraft 1.21.11
### 1.1.0—1.21.10
* Changed GUI trigger from Right-Click to Shift+Right-Click, preventing accidental block placement regardless of what you're holding
* Fixed holding a block while opening the GUI consuming one block from your inventory
* Updated tooltip color
* Improved bee count and honey level refresh in the GUI to update in real-time when bees enter or exit the hive, matching the responsiveness of vanilla container GUIs
* Removed unused mixin leftover from the mod template
### 1.0.0—1.21.10
* Initial Release
